# План приложения MoveBeat Track Assistant

## Цель

Дать пользователю графическое приложение, которое подготавливает совместимые с
MoveBeat уровни без ручного запуска Python-команд. Основная поддерживаемая
версия — Windows/ПК. Android-клиент должен использовать тот же формат результата
и появится после отдельной проверки жизнеспособности.

Ассистент не распространяет музыку и карты вместе с MoveBeat. Пользователь сам
выбирает карту и подтверждает, что вправе сохранить и перенести её файлы.

## Общий формат результата

Первым шагом необходимо зафиксировать версионированный формат переносимого
набора `MoveBeat Level Bundle`:

- `level.ini` с источником, авторами, BPM и перечнем сложностей;
- один или несколько файлов `.mbchart`;
- Ogg/Vorbis-аудио под безопасным именем;
- необязательная обложка;
- подготовленная на ПК карточка `library.mblc` 512×96 RGB565 с обложкой
  96×96, названием и исполнителем; файл записан в отчёт целостности;
- `conversion-report.json` с версией конвертера, SHA-1 исходной версии,
  предупреждениями и количеством импортированных/пропущенных объектов.

Папка и ZIP этого формата должны одинаково приниматься ПК-ассистентом, будущим
Android-клиентом и скриптом сборки PS3.

## Этап B — приложение для ПК

Предварительный выбор — Python 3 + Tkinter для интерфейса и PyInstaller для
автономной Windows-сборки. Это позволяет переиспользовать уже проверенный
импортёр без второго независимого конвертера. Перед реализацией нужно собрать
минимальный prototype и проверить размер/запуск итогового EXE.

- [x] перенести уже работающий CLI-поиск BeatSaver по названию/ключу в GUI;
- [x] показывать сложности в списке, а для выбранной карты — исполнителя,
  BPM, оценку, число голосов вверх/вниз, загрузки/игры и дату выбранной версии;
  для локального ZIP также показывается размер файла;
- [x] показывать обложку выбранной BeatSaver-карты или локального ZIP:
  загрузка асинхронная, 4 МиБ максимум на входе, предпросмотр 144×144 и лимит
  16 Мпикс для защиты памяти;
- [x] асинхронно показывать заявленный BeatSaver размер удалённого ZIP через
  `HEAD` или однобайтовый `Range` fallback; если сервер не сообщает размер,
  явно показывать, что он неизвестен; свыше лимита 20 МиБ предупреждать до загрузки;

- [x] экран состава уровней и предупреждений конвертера до публикации bundle в

- [x] выбор сложностей и характеристик для экспорта;
- [ ] библиотека подготовленных уровней с удалением только после подтверждения;
- [x] экспорт в `out/levels` или отдельную папку;

## Этап C — Android feasibility и приложение

Android не будет собирать или подписывать PS3 PKG. Он подготавливает bundle,
который затем копируется в библиотеку MoveBeat либо передаётся ПК-ассистенту.

- [x] prototype на Kotlin: BeatSaver search, HTTPS-download, SHA-1 и чтение ZIP;
- [ ] проверить память и время конвертации большой v3/v4-карты на среднем
  Android-устройстве;
- [x] проверить, что типичные `.egg` действительно можно переносить как Ogg
  без тяжёлого мобильного транскодера;
- [x] добавить JVM golden-тест Kotlin/Python для карт v2/v3/v4: сравнение
  `level.ini`, `.mbchart` и смысловых полей отчёта без Android SDK;
- [ ] принять решение о полном Android-релизе по результатам prototype;
- [x] реализовать выбор локального ZIP и сохранение результата через Storage
  Access Framework без требования полного доступа к файловой системе;
- [ ] проверить на физическом Android-устройстве экспорт bundle/ZIP в выбранную
  папку или USB-носитель (эмулятор проверен, устройство пока не подключалось);
- [x] передача подготовленного bundle по FTP на PS3: явный адрес, фиксированный
  путь библиотеки, подтверждение перед отправкой, staged-upload, чтение файлов
  обратно и сверка SHA-256; существующий ID не перезаписывается;
- [x] не хранить пароль FTP и предупреждать о передаче без шифрования;
- [x] реализовать офлайн-импорт заранее скачанного ZIP;
- [ ] Android UI-тесты и golden-тесты формата bundle.

30.09.2026: FTP-клиент собран в Debug APK. Три локальных JVM-теста покрывают
успешную staged-публикацию, отказ при существующем ID и очистку staging при
ошибке контрольного чтения. APK установлен и запущен в Android 36 эмуляторе;
форма FTP и предупреждение видны. Передача на настоящую PS3 и проверка на
физическом Android остаются открытыми.

Если prototype покажет, что аудиоподготовка требует слишком тяжёлого или
юридически неудобного кодека, Android-версия остаётся менеджером уже
совместимых Ogg-карт и клиентом передачи, а полная конвертация выполняется на
ПК. Это ограничение должно быть показано пользователю до скачивания карты.

## Порядок реализации

1. Спецификация bundle и отчёта.
2. Рефакторинг общего Python-ядра с сохранением текущего CLI.
3. Минимальный Windows GUI и portable-сборка.
4. Полный ПК workflow BeatSaver → проверка → bundle → FTP на PS3 или
   персональный PKG.
5. Kotlin feasibility prototype и сравнение golden-результатов.
6. Android-релиз либо документированно ограниченный мобильный менеджер.

## Что не входит в ассистент

- обход авторизации, платного доступа или ограничений BeatSaver;
- публикация чужих карт и музыки;
- загрузка BeatSaver непосредственно с PS3;
- сборка PS3 homebrew toolchain на Android;
- фоновая запись файлов на PS3 без явного выбора назначения и подтверждения
  пользователя.
